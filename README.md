# AI Video Generator

This is a simple AI video generator project.

The goal of this project is to create relaxing AI videos about peaceful Vietnamese countryside life using AI-generated images and simple animation.

## Features

- Generate images from prompts
- Turn images into simple videos
- Create storytelling scenes
- Export videos for social media

## Example Scenes

- Vietnamese rice fields
- Traditional countryside houses
- Children playing traditional games
- Farmers working in the fields
- Sunset over village rivers

## Workflow

1. Write prompts for scenes
2. Generate AI images
3. Convert images into video clips
4. Combine clips into a short video

## Example Prompt

peaceful vietnam countryside village, rice fields, sunset light, cinematic atmosphere, ultra realistic
